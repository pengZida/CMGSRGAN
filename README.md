# CMGSRGAN
This repository contains the source code for the paper "Unregistered dermoscopy-guided enhanced super-resolution of clinical skin tumor images via cross-modal GAN" in 《the Visual Computer》.
# Requirements
torch==1.8.0
torchvision==0.9.0
numpy==1.21.6
pillow==9.5.0
# Data
Due to confidentiality agreement requirements, the Xiangya skin tumor dataset used in this paper cannot be utilized. It is recommended to employ the seven-point checklist dataset for test.
# Important Notice
The code is still being updated in line with the paper's peer review revisions. All pre-trained model weights will be uploaded soon.
