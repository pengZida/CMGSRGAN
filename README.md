# CMGSRGAN
This repository contains the source code for the paper "Cross-Modal Guided GAN for Enhanced Super-Resolution of Clinical Skin Tumor Images".
# Requirements
torch==1.8.0
torchvision==0.9.0
numpy==1.21.6
pillow==9.5.0
# Data
Due to confidentiality agreement requirements, the Xiangya skin tumor dataset used in this paper cannot be utilized. It is recommended to employ the seven-point checklist dataset for test.
